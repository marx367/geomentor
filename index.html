🎛️ Expresiones

¿Cómo escribo las expresiones?
  • Parámetro con deslizador: a = 2
  • Función: y = a x^2 + b x + c o f(x) = sen(x)
  • Ecuación (cónicas): x^2/9 + y^2/4 = 1
  • Recta vertical: x = 3
  • Punto: A = (2, 3) · Vector: u = vector(3, 4) o vector(A, B)
  • Segmento: segmento(A, B) · Recta: recta(A, B) o recta(A, u)
  • Cálculos: u*v (producto escalar), norma(u), angulo(u, v) en grados, cruz(u, v) con vectores de R³ como (1, 2, 3)
  • Funciones: sen cos tan sqrt abs ln log exp, constantes pi y e. Líneas que empiezan con // son comentarios.
